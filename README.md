A one-sentence pitch that convinces a friend who has never coded to let an AI agent build their first app idea on make.fun. `main.py` writes that single sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```
